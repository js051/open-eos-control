# Live View journey evidence v1

One source owner must survive camera-start response, first complete valid input, decoded output, presentation, terminal failure and Stop cleanup. Evidence layers are distinct: encoded-frame means a validated complete JPEG or complete access unit with required parameter sets; decoded-frame means actual decoder output; presented-frame means the platform presentation path has accepted that output. Neither listener-ready, HTTP headers nor Start ACK creates frame evidence. None of these proves a physical display was seen by the user.

The shared pure evaluate policy is a necessary publication/fallback guard, not validation of bytes or proof that I/O occurred. Production receivers retain their real validation and same-owner generation checks. Input readiness, decoded output and presentation are separate outputs. Publication requires stopEvidence=pending, meaning the active source has not produced a Stop result; unconfirmed or unknown Stop evidence cannot publish. A terminal source publishes none of them. Cancellation, retirement, replacement owner/attempt and a mobile foreground requirement suppress publication and fallback, without dropping an admitted source's Stop responsibility. Desktop background monitoring may deliberately keep foregroundRequired=false.

AUTO may try another advertised source only after the failed original source's Stop is confirmed, or when no start was admitted and no Stop was needed. Uncertain cleanup blocks fallback. Explicit sources never silently switch. No unknown Start is replayed. Runtime failure clears stale presentation and uses original Stop-only recovery; after cleanup a deliberate Start or an already-defined safe foreground restoration is a new attempt. An old reader, frame, timer or cleanup reply cannot affect it.

All waits must have cancellation and bounded first-input/output or inactivity limits. Platform source/decoder callbacks provide real evidence; a valid access unit is never promoted into decoded pixels merely to make tests pass. Shared fixtures and source checks do not establish native decoder, UI, network or physical-camera execution.
