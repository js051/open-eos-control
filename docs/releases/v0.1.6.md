# Open EOS Control v0.1.6 Development Preview

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

這是 Open EOS Control 的第七個開發預覽版。本版聚焦 Android 相機式方向操作：畫面骨架維持固定，必要的控制與狀態內容會依手機方向原地旋轉，且完整文字不再因側向顯示而被省略。

### Android 方向操作

- 預設跟隨 Android 系統的「自動旋轉」設定；系統關閉時，手機側放也不會旋轉 App 內容。
- 可在 App 內改選「一律旋轉」或「保持固定」，方便相機支架與特殊拍攝姿勢。
- 取景框、頂部狀態列、曝光列與快門位置不隨手機方向重排；圖示、數值與必要狀態文字在原位置旋轉。
- 90／270 度時會交換可讀內容的量測軸，讓完整英文與繁體中文說明使用取景區的橫向空間，不以隱藏文字換取版面穩定。
- Live View 設定等閱讀量較大的面板會以使用者視角重新量測，避免窄欄文字擠壓與截斷。
- 診斷報告新增方向模式、系統自動旋轉狀態與實際控制角度。

### 下載

- `open-eos-control-android-0.1.6-debug.apk`：使用固定開發簽章的 Android 可側載版本，可直接覆蓋 `0.1.5`。
- `open-eos-control-bridge-windows-x64-0.1.6.exe`：Windows x64 單檔 Desktop Bridge。
- `open_eos_control_bridge-0.1.6-py3-none-any.whl` 與 `.tar.gz`：Desktop Bridge Python 套件。
- `SHA256SUMS.txt`：所有附件的 SHA-256 校驗值。

### 已知限制

- 此簽章只用於開發預覽版，不是正式商店發佈簽章。
- 並非所有功能都已在 EOS R6 Mark III 完成完整真機回歸；功能仍以相機或 backend 的可用能力公告為準。
- iOS 仍不提供已簽署 IPA，Windows USB 仍需系統提供 `gphoto2`／libgphoto2。

## English

This is the seventh Open EOS Control development preview. It focuses on camera-style Android orientation behavior: the camera composition stays fixed while essential controls and status content rotate in place, without dropping readable copy in sideways use.

### Android Orientation

- The default follows Android's system auto-rotate setting. When system auto-rotate is off, turning the phone does not rotate app content.
- Always rotate and keep fixed alternatives are available in the app for camera rigs and unusual shooting positions.
- The viewfinder, top status bar, exposure strip, and shutter placement do not reflow with device orientation. Icons, values, and essential status text rotate in place.
- At 90 and 270 degrees, readable content swaps its measurement axes so full English and Traditional Chinese copy can use the viewfinder's horizontal space instead of being hidden.
- Reading-heavy surfaces such as Live View settings are remeasured in the user's viewing direction to avoid narrow columns and clipped text.
- Diagnostics now include the orientation policy, system auto-rotate state, and effective control angle.

### Downloads

- `open-eos-control-android-0.1.6-debug.apk`: sideloadable Android build using the stable development signer; it can update `0.1.5` in place.
- `open-eos-control-bridge-windows-x64-0.1.6.exe`: single-file Windows x64 Desktop Bridge.
- `open_eos_control_bridge-0.1.6-py3-none-any.whl` and `.tar.gz`: Desktop Bridge Python packages.
- `SHA256SUMS.txt`: SHA-256 checksums for every attached file.

### Known Limitations

- This identity signs development previews only; it is not a production app-store signing identity.
- Not every capability has completed a full EOS R6 Mark III physical regression pass. Controls remain gated by camera/backend advertisement.
- This release still has no signed iOS IPA, and Windows USB control still requires system-provided `gphoto2`/libgphoto2.
