# Open EOS Control v0.6.0 Development Preview

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

這個 `0.6.0` 開發預覽版讓 Android 相機媒體流程第一次能以有邊界、可驗證的方式交接到 Serein。剛拍完的單張照片或多選素材可以直接送往相簿／編修端，不需要先逐張匯出再切換 App 尋找檔案。

### Android 交接至 Serein

- 單一素材與相機媒體多選都可使用「在 Serein 編輯」。只有裝置上存在相容接收端時才會啟動交接。
- Open EOS Control 會先完整暫存每個 original、核對長度並計算 SHA-256，再以限時、唯讀的 `content://` URI 授權交給接收端；不會把 CCAPI、PTP 或 Bridge 位址暴露給另一個 App。
- 回到 Open EOS Control 時，只接受 action、MIME、session 與全部 media ID 都精確相符的回執批次，並再次核對已匯入檔案的位元組長度與 SHA-256。
- 接收端失敗、取消、缺少回執或回傳不相符資料都不會被顯示成成功，也不會授權刪除或修改相機媒體。

### Camera Import Contract 1.1.0

- Release 新增 `open-eos-camera-import-contract-1.1.0.zip`，包含 JSON Schema、相容性宣告、語意規則及可攜式 valid／invalid fixtures。
- 同時提供可重現的純 Kotlin `open-eos-camera-import-contract-kotlin-1.1.0.jar`，供 Android 接收端共用嚴格 codec 與模型。
- 契約明確分開 transport ownership 與 Catalog／顯影 ownership，並規定精確重複判定、傳輸證據、取消狀態及不授權來源刪除的回執語意。
- Android 也修正相機端錄影事件同步，機身開始或停止錄影後不需手動重新整理即可更新狀態。

### 驗證與限制

- 已在乾淨的 Pixel API 34 AVD 安裝兩邊 PR exact-head 的 Open EOS Control 與 Serein debug APK，走完兩筆素材交接、嚴格 preflight、匯入／精確重複判定及回執返回；Open EOS 的 API 34、API 36、單元測試與完整 CI 也已通過。
- Serein 目前仍是私人 companion 專案，尚未提供公開接收端下載；沒有相容接收端時，App 會清楚回報不可用。
- 尚未以實體 Android 手機和 EOS R6 Mark III 走完 Camera-to-Catalog、長時間大量傳輸、強制中止／續傳與 checksum mismatch 真機矩陣，因此本版不宣稱這些路徑已完成實機驗證。
- PC 與 iOS 本版沒有 Serein 交接介面；既有相機控制與媒體功能不受影響。
- `open-eos-control-android-0.6.0-debug.apk` 沿用固定開發簽章，可覆蓋安裝 v0.1.5 之後的同簽章預覽版。本版仍是 Development Preview，不是穩定版。

## English

This `0.6.0` development preview gives Android camera media a bounded, verifiable handoff to Serein for the first time. A recent capture or a media selection can move directly into the catalog/editing side without exporting each file and locating it again in another app.

### Android Handoff To Serein

- Both a single media item and a camera-media selection offer Edit in Serein. Handoff starts only when a compatible receiver is installed.
- Open EOS Control fully stages each original, verifies its length, computes SHA-256, and grants time-bounded read-only `content://` access. CCAPI, PTP, and Bridge locators are never exposed to the receiving app.
- On return, Open EOS Control accepts only a receipt batch whose action, MIME type, session, and complete media-ID set match exactly, then verifies imported byte lengths and SHA-256 values again.
- Receiver failure, cancellation, missing receipts, or mismatched data are never reported as success and never authorize deletion or mutation of camera media.

### Camera Import Contract 1.1.0

- The release adds `open-eos-camera-import-contract-1.1.0.zip` with JSON Schemas, compatibility declarations, semantic rules, and portable valid/invalid fixtures.
- A reproducible pure-Kotlin `open-eos-camera-import-contract-kotlin-1.1.0.jar` provides strict shared models and codecs for Android receivers.
- The contract separates transport ownership from catalog/development ownership and defines exact duplicate evidence, transfer state, cancellation, and non-authorizing receipt semantics.
- Android also fixes camera-side recording event synchronization so recording state updates without a manual refresh.

### Validation And Limitations

- A clean Pixel API 34 AVD ran the exact-head Open EOS Control and Serein PR debug APKs through a two-item handoff, strict preflight, import/exact-duplicate handling, and verified receipt return. Open EOS API 34, API 36, unit, and full CI coverage also passed.
- Serein remains a privately distributed companion project at this preview stage, so no public receiver download is available yet. The app reports unavailability clearly when no compatible receiver is installed.
- A physical Android phone plus EOS R6 Mark III has not yet completed Camera-to-Catalog, sustained large transfer, forced termination/resume, or checksum-mismatch validation. This release makes no claim that those paths have physical-device evidence.
- PC and iOS do not receive the Serein handoff UI in this release. Existing camera-control and media features remain available.
- `open-eos-control-android-0.6.0-debug.apk` retains the stable development signer and can update matching previews from v0.1.5 onward. This remains a Development Preview, not a stable release.
