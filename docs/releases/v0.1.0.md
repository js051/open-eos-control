# Open EOS Control v0.1.0 Development Preview

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

這是 Open EOS Control 的第一個開發預覽版，優先支援 Canon EOS R6 Mark III 的真機驗證流程。專案仍在快速迭代，請勿把此版本視為正式拍攝工具。

### 下載

- `open-eos-control-android-0.1.0-debug.apk`：可直接側載的 Android debug build，使用 Android SDK debug 憑證簽署。
- `open_eos_control_bridge-0.1.0-py3-none-any.whl`：PC Desktop Bridge Python wheel。
- `open_eos_control_bridge-0.1.0.tar.gz`：PC Desktop Bridge source distribution。
- `SHA256SUMS.txt`：上述發布檔案的 SHA-256 校驗值。

Android APK 不是正式簽署版本；升級後若簽章不同，可能需要先解除安裝舊版。Desktop Bridge 的 USB 控制仍需要系統安裝 `gphoto2`／libgphoto2。iOS 本版僅提供原始碼；實機版本需使用 Xcode 自行建置與簽署。

### 主要內容

- Android、iOS、PC Desktop Bridge 的 Canon CCAPI 控制。
- Android USB/PTP 與依能力開放的 Canon EOS USB 控制。
- JPEG Live View，以及相機公告能力時可用的 RTP H.264 Live View。
- 可調整 1-30 FPS 顯示上限、拍照、錄影、曝光、白平衡、對焦、媒體與診斷流程。
- 英文、繁體中文與不連接相機即可查看的離線 UI 預覽。
- Simulator、跨平台契約測試、公開協定依據與提交前機密掃描。

### 已知限制

- 尚未完成所有功能在 EOS R6 Mark III 上的完整真機回歸測試。
- 功能只會在相機或 backend 公告支援能力時顯示；不支援的命令不會以假按鈕代替。
- Android debug APK 僅供測試。iOS 沒有預先簽署的實機 IPA。
- Canon CCAPI RTP 目前僅處理 H.264 影像，不處理音訊。

## English

This is the first Open EOS Control development preview, prioritizing physical validation with the Canon EOS R6 Mark III. The project is still evolving quickly and should not be treated as a production capture tool.

### Downloads

- `open-eos-control-android-0.1.0-debug.apk`: directly sideloadable Android debug build signed with the Android SDK debug certificate.
- `open_eos_control_bridge-0.1.0-py3-none-any.whl`: PC Desktop Bridge Python wheel.
- `open_eos_control_bridge-0.1.0.tar.gz`: PC Desktop Bridge source distribution.
- `SHA256SUMS.txt`: SHA-256 checksums for the attached release files.

The Android APK is not production-signed and may require uninstalling an older build if its signing certificate differs. USB control through the Desktop Bridge still requires system-provided `gphoto2`/libgphoto2. iOS is source-only in this release; device builds must be built and signed with Xcode.

### Highlights

- Canon CCAPI control for Android, iOS, and the PC Desktop Bridge.
- Android USB/PTP and capability-gated Canon EOS USB control.
- JPEG Live View plus RTP H.264 Live View when advertised by the camera.
- Adjustable 1-30 FPS display cap, still capture, recording, exposure, white balance, focus, media, and diagnostics.
- English, Traditional Chinese, and an offline UI preview that does not require a camera.
- Simulator, cross-platform contract tests, pinned public protocol evidence, and pre-push secret scanning.

### Known Limitations

- Not every feature has completed a full physical regression pass on the EOS R6 Mark III.
- Controls appear only when the camera or backend advertises support; unsupported commands are not represented by placeholder buttons.
- The Android debug APK is for testing only. No pre-signed physical-device iOS IPA is provided.
- Canon CCAPI RTP currently handles H.264 video only, without audio.
