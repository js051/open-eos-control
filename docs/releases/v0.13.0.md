# Open EOS Control v0.13.0 Development Preview

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

`0.13.0` 串接 Android 前景 JPEG 自動儲存、手機本次已存原檔清單，以及相機斷線後的 Serein 交接；另修復 iOS Live View 點按對焦／白平衡模式的選取。這組新使用者功能採 minor 版號，仍是供測試與回饋的 **Development Preview**，不建議用於正式拍攝流程。

### 使用方式與範圍

1. 使用 Android 10+ 直接連線 CCAPI，從相簿開啟前景自動儲存，閱讀新 JPEG 範圍、儲存位置、前景限制及清理提醒後啟用。
2. 等待兩次完整、有界且相符的起始清單完成。原本已存在的檔案不會補匯入；起始最多 2000 項，清單不完整或超限時顯示原因並停止。
3. 保持 App 在前景。只有新觀察到、符合 JPEG 條件且兩次新鮮正數大小在至少一秒間隔後一致的候選，才以單次原檔 GET 寫入 MediaStore pending row；完整寫入、關閉及長度確認後才公開至 Gallery。新 ID 只代表新觀察，不保證是本次連線或本次快門拍攝。
4. 查看排隊與完成結果，或按 Stop。記憶項上限 4096，排隊含保存中的上限 20；超限或部分 listing 不會被當成成功掃描。Stop、背景與連線替換會取消並等待本次工作清理；回前景或重新連線都要再次明確啟用。

清理未確認會留下可見警告；確認警告不等於檔案已清除。已公開的完整原檔不因稍後取消或紀錄失敗而刪除。自動下載失敗不重試原檔或重播快門、錄影、對焦等相機命令。控制畫面沒有匯入狀態列時維持原完整 viewport，有狀態列時只消耗一次系統 insets；held-AF、縮放及安全區域斷言均保留。

### 已存 JPEG → Serein

1. 自動匯入或手動將相機 JPEG 原檔保存至 Gallery 後，從連線頁或相簿開啟「本次 JPEG」。只有完整公開成功的原檔會列入；斷開相機後也可選片。
2. 若前景自動匯入仍在執行，先明確按 Stop，等待本次清理完成，再選取傳送。最多 100 張的提交快照固定後，Close／Back 不會取消已交出的工作；清除清單只清參照，不刪 Gallery 原檔。
3. 交接只讀已持有的本地原檔，核對完整長度與公開時的 SHA-256，再以暫時唯讀授權交給已安裝的相容 Serein。原檔遺失、同長度內容被改、空間不足或回執不符都會顯示失敗，不回相機重新下載。清理或撤權未確認會保留警告，明確 Retry 才再清理。

這不是自動啟動 Serein 或長期照片索引。暫存逐批／逐檔預留 64 MiB 空間，接收端仍會做自己的容量與來源檢查；EOS 先核對整批回執的 session、provider 與完整項目覆蓋；已匯入／重複項目另須完整長度及 hash 相符，失敗／取消項目則如實顯示狀態。

### iOS Live View 點按模式

相機具備點選白平衡能力時，可用兩個明確選項按鈕切換點按對焦／點按白平衡；選取狀態、輔助使用語意與至少 44 pt 的觸控範圍保留。切換本地模式或關閉／重開選單不發送相機命令；在影像上實際點按才送出對應的一次操作。此修復不宣稱查明 UIKit 原生分段選單的內部原因。

### 升級與限制

- Android **0.13.0 / versionCode 29**，沿用 Preview package 與固定開發簽章；更新需相同 package／簽章，隔離 `.debug` 測試 App 仍為另一安裝。
- iOS **0.13.0 / build 27**、Bridge／Simulator 同步產品版本；新增前景匯入限 Android 直接 CCAPI，版號同步不代表 iOS、PC、USB 或 Bridge 有等效功能。沒有已簽署 IPA。
- Camera Import artifact **1.1.0**／wire **1.0** 不變。離線交接限本次 App 保留的最近 100 張已公開 Gallery JPEG，不是全手機相簿索引。旋轉及 Disconnect 保留；真正結束 Activity／程序重啟不保證保留。沒有 RAW 轉換、背景常駐、舊檔回灌、跨 session 去重或程序終止後續傳。
- 下載紀錄與本次 JPEG 清單分開：紀錄仍讀 schema 1／2、寫 schema 2，不保存可重新開啟的 Gallery URI，也不驗證檔案仍存在或來源 checksum；交接清單則使用本次公開原檔的長度與 hash 證據。較早 schema-1-only 開發建置不保證無損降版。
- [v0.12.0 的限制](v0.12.0.md)仍適用：Close 不取消仍在載入的 display HTTP，USB 更廣泛的過期 storage 狀態發布尚未解決，完整 RAW 顯影、藍牙配對及跨平台功能一致性仍未完成。
- iOS 的 Bulb Start HTTP 尚未結束時，現有 Stop／Disconnect 仍可能等待啟動請求；本版尚未包含該取消／恢復路徑的後續修復。
- 跨 App 驗收使用不同 UID 的測試接收器，證明 wire、暫時授權與回執處理；實際 Serein App 的 catalog 導入／編修旅程尚未聯合驗證。
- 沒有新增實體 EOS／手機／實際 Wi-Fi 驗收。R6 Mark III 大卡、弱網、其他機型／韌體、光學對焦與相機真實狀態仍需對應 device evidence；不能用 synthetic HTTP／emulator 通過替代。

## English

`0.13.0` connects Android foreground JPEG saving, the current app-run list of saved originals, and offline handoff to Serein after camera disconnection. It also repairs iOS Live View tap-focus/white-balance selection. These user capabilities warrant a minor version. It remains a **Development Preview** for testing and feedback, unsuitable for production camera workflows.

### Use and scope

1. On Android 10+, connect directly with CCAPI and enable foreground saving from Gallery after reviewing the new-JPEG scope, destination, foreground requirement and cleanup notice.
2. Wait for two matching, complete bounded starting inventories. Existing files are excluded, with a 2000-item starting limit. Partial or oversized listings stop visibly.
3. Keep the app foregrounded. Newly observed JPEG candidates require two fresh positive sizes that remain equal at least one second apart. Each admitted original uses one GET into a MediaStore pending row and becomes public only after complete write, close and length validation. A new ID means newly observed, not proven capture by this connection or shutter action.
4. Watch queue/completion feedback or press Stop. Remembered IDs are capped at 4096 and the queue, including the active save, at 20. Partial/oversized listings cannot pass as complete. Stop, background and connection replacement cancel and await owned cleanup; returning or reconnecting requires explicit re-enabling.

Unconfirmed cleanup remains visible; acknowledging the notice does not delete a file. Finalized originals survive later cancellation or history-write failure. Failed automatic transfers do not retry originals or replay shutter, recording or focus commands. The original full control viewport is retained without an import status row; when present, system insets are consumed once, preserving held-AF, zoom and safe-area assertions.

### Saved JPEGs → Serein

1. After automatic delivery or a manual original-JPEG save to Gallery, open the current JPEG list from the connection screen or camera gallery. Only fully published originals are admitted, and selection remains available after disconnecting the camera.
2. If foreground delivery is active, explicitly press Stop and wait for owned cleanup before sending. Submission freezes a maximum 100-item snapshot. Close/Back does not cancel an external handoff; clearing the list removes references without deleting Gallery originals.
3. Preparation reads only the retained local originals, checks complete length and the publication-time SHA-256, then gives an installed compatible Serein temporary read-only access. Missing originals, same-length replacement, insufficient space or mismatched receipts fail visibly without downloading again from the camera. Unconfirmed cleanup/revocation keeps a warning until an explicit retry.

This does not start Serein automatically or create a persistent photo index. Staging reserves 64 MiB for the batch and each file; the receiver still performs its own source and capacity checks. EOS first verifies the receipt’s session, provider and complete item coverage. Imported/duplicate items additionally require matching byte lengths and hashes; failed/cancelled items retain their reported outcome.

### iOS Live View tap modes

When the camera advertises click-white-balance support, two explicit buttons select tap focus or tap white balance, retaining selected accessibility semantics and at least 44 pt hit targets. Changing the local mode or closing/reopening its menu sends no camera command; an actual image tap sends the selected operation once. This repair does not claim UIKit's internal segmented-control cause.

### Upgrade and limitations

- Android is **0.13.0 / versionCode 29**, retaining the Preview package and development signer. In-place updates require the same package/signer; isolated `.debug` builds remain separate.
- iOS is **0.13.0 / build 27**, and Bridge/Simulator product versions match. Foreground import is Android direct CCAPI only; matching versions add no iOS/PC/USB/Bridge equivalent. No signed IPA is supplied.
- Camera Import artifact **1.1.0** / wire **1.0** is unchanged. Offline handoff uses only the latest 100 finalized Gallery JPEGs retained by the current app run; it is not a phone-wide gallery index. Rotation and Disconnect retain this list; ending the Activity or restarting the process does not guarantee retention. RAW conversion, persistent background service, old-file backfill, cross-session deduplication and process-resumable transfer are not added.
- Download history is separate from the current JPEG list: history still reads schemas 1/2 and writes schema 2 without reopenable Gallery URIs, file-existence checks or source-checksum verification; the handoff list uses this run’s published-original length/hash evidence. Lossless downgrade to earlier schema-1-only development builds is not guaranteed.
- [v0.12.0 limitations](v0.12.0.md) remain: Close does not cancel pending display HTTP work; broader stale USB storage-state publication, full RAW development, Bluetooth pairing and platform parity remain unresolved.
- An unfinished iOS Bulb Start HTTP request can still delay Stop/Disconnect. Its pending-request cancellation/recovery repair is outside this version.
- Cross-app acceptance uses a separate-UID test receiver to verify wire behavior, temporary grants and receipts. The actual Serein App’s catalog/import/edit journey has not been jointly validated.
- No new physical EOS/phone/Wi-Fi evidence is supplied. R6 Mark III large cards, weak networks, other models/firmware, optical focus and actual camera state require corresponding device evidence. Synthetic HTTP and emulator passes do not establish those claims.
