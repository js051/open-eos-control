# Open EOS Control v0.1.2 Development Preview

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

這是 Open EOS Control 的第三個開發預覽版。本版著重於實際拍攝操作、相機式方向行為、Live View 監看工具與跨平台媒體傳輸。真機驗證仍以 Canon EOS R6 Mark III 為優先；此版本仍是測試用途，不應視為正式拍攝工具。

### 下載

- `open-eos-control-android-0.1.2-debug.apk`：可側載的 Android debug 版本，以 Android SDK debug 憑證簽署。
- `open_eos_control_bridge-0.1.2-py3-none-any.whl`：PC Desktop Bridge Python wheel。
- `open_eos_control_bridge-0.1.2.tar.gz`：PC Desktop Bridge 原始碼套件。
- `SHA256SUMS.txt`：所有附件的 SHA-256 校驗值。

Android APK 並非正式簽章；若舊版使用不同憑證，可能需要先解除安裝。Desktop Bridge 的 USB 控制仍需系統提供 `gphoto2`／libgphoto2。iOS 目前只提供原始碼，實體裝置版本需使用 Xcode 自行建置與簽署。

### 重點更新

- Android 採用固定相機骨架：Live View、曝光列與快門位置不隨手機姿勢重排，只旋轉各自量測過的圖示、短文字與狀態內容。
- 相機型號、電量與剩餘張數改為獨立緊湊 HUD 單元；完整資訊保留於無障礙描述，90°／180°／270° 不再因長字串互相覆蓋。
- 中央提示與設定內容會在 90°／270° 先交換量測軸並切換寬版排列，繁中與放大字體仍維持在安全區域內。
- 相機控制方向跟隨 Android 系統自動旋轉設定；關閉時固定為螢幕方向，開啟時使用具遲滯的感測器象限判定。
- Android 拍照／錄影模式切換、曝光調整與忙碌狀態更一致，並新增 histogram、zebra、false color、focus peaking、frame guide、safe area 與 anamorphic desqueeze。
- Android、iOS 與 PC 增加有線媒體預覽；iOS 與 PC 的媒體下載顯示進度並支援取消。
- iOS 與 PC 新增 Live View 監看輔助；PC 大檔下載可在支援的瀏覽器直接串流寫入檔案，避免整份資料留在記憶體。
- CI 會執行 Android 單元、lint、組建及 Pixel API 34 UI 測試，並測試 iOS core／app、Desktop Bridge、Simulator 與完整 Git 歷史敏感資訊掃描。

### 已知限制

- 並非所有功能都已在 EOS R6 Mark III 完成完整真機回歸；未由相機公告的能力不會顯示或送出命令。
- Android 旋轉行為已在 Pixel API 34 AVD 驗證；不同廠牌的系統設定通知仍需要更多實體裝置回報。
- Android APK 僅供測試。此 release 不提供已簽署的 iOS IPA 或桌面原生安裝程式。
- Canon CCAPI RTP 目前只處理 H.264 視訊，不含 AAC LATM 音訊。

## English

This is the third Open EOS Control development preview. It focuses on practical capture controls, camera-style orientation behavior, Live View monitoring tools, and cross-platform media transfer. Physical validation still prioritizes the Canon EOS R6 Mark III; this release remains a test build and should not be treated as a production capture tool.

### Downloads

- `open-eos-control-android-0.1.2-debug.apk`: sideloadable Android debug build signed with the Android SDK debug certificate.
- `open_eos_control_bridge-0.1.2-py3-none-any.whl`: PC Desktop Bridge Python wheel.
- `open_eos_control_bridge-0.1.2.tar.gz`: PC Desktop Bridge source distribution.
- `SHA256SUMS.txt`: SHA-256 checksums for all attached files.

The Android APK is not production-signed and may require uninstalling an older build if its signing certificate differs. Desktop Bridge USB control still requires system-provided `gphoto2`/libgphoto2. iOS remains source-only; physical-device builds must be built and signed with Xcode.

### Highlights

- Android now keeps a fixed camera frame: Live View, exposure controls, and the shutter stay in place while individually measured icons, short labels, and status values rotate.
- Camera identity, battery, and remaining-shot information use independent compact HUD atoms with full accessibility descriptions, avoiding long-string overlap at 90, 180, and 270 degrees.
- Central guidance and settings content exchange measurement axes and use a wide layout at quarter turns, keeping Traditional Chinese and enlarged text inside safe bounds.
- Control rotation follows the Android system auto-rotate setting. Rotation lock keeps controls aligned with the display; enabled auto-rotation uses a hysteresis-filtered sensor quadrant.
- Android capture-mode switching, exposure adjustment, and busy states are more consistent, with histogram, zebra, false color, focus peaking, frame guides, safe area, and anamorphic desqueeze monitoring tools.
- Android, iOS, and PC add wired media previews. iOS and PC media downloads now report progress and support cancellation.
- iOS and PC add Live View monitoring assists. Large PC downloads can stream directly to disk in supported browsers instead of retaining the entire file in memory.
- CI runs Android unit, lint, build, and Pixel API 34 UI tests alongside iOS core/app, Desktop Bridge, Simulator, and full-history secret scanning.

### Known Limitations

- Not every feature has completed a full physical regression pass on the EOS R6 Mark III. Commands are exposed only when the camera or backend advertises the required capability.
- Android orientation behavior is verified on a Pixel API 34 AVD; system-setting notifications on additional vendor devices still need physical-device reports.
- The Android APK is for testing only. This release does not include a signed iOS IPA or native desktop installer.
- Canon CCAPI RTP currently handles H.264 video only, without AAC LATM audio.
