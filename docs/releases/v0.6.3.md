# Open EOS Control v0.6.3 Development Preview

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

這個 `0.6.3` 開發預覽版修正 Android 近期相機媒體在照片與影片分屬不同 Canon 容器時的排序，並改善大量唯讀操作遇到暫時性連線逾時時的恢復與錯誤提示。這是 `0.6.2` 的向下相容修正版。

### 近期媒體

- 「最近拍攝」會在有資料時，以 Canon 媒體資訊中的實際修改時間合併照片與影片，不再因容器輪詢讓數月前的影片混入最新照片之間。
- 時間資訊讀取維持有界；相機未提供日期或暫時無法讀取時，介面保留可預測的相機容器順序，不臆測拍攝日期。

### 大量唯讀操作

- 縮圖、預覽、原檔下載與傳送至 Serein 前的暫存，會對暫時性 I/O 中斷進行有限重試，且每次重試使用新的目的檔，避免沿用不完整內容。
- metadata 寫入與刪除等狀態變更操作不會盲目重試，以免相機已套用操作但回應遺失時重複執行。
- 一般模式改為顯示可理解的繁中／英文逾時與重新連線提示；原始例外仍保留於 Debug 診斷。

### 驗證與限制

- PR #178 的 Android 單元測試、Lint、APK、簽章 smoke test，以及 Pixel API 34／36 UI 矩陣均通過。
- HTC U24 Pro 已以獨立 debug package 通過本地化逾時提示的 Compose 真機測試，不覆蓋已安裝的 Development Preview。
- 本輪驗證時 Canon EOS R6 Mark III 已關機，因此實際近期媒體跨容器排序與傳輸中斷恢復仍待相機再次開啟後驗收；本版不據此宣稱新的機型相容性。
- 本版產品行為變更只在 Android；PC 與 iOS 維持版本對齊的發行產物，沒有相對應行為變更。
- `open-eos-control-android-0.6.3-debug.apk` 沿用固定開發簽章，可覆蓋安裝 v0.1.5 之後的同簽章預覽版。本版仍是 Development Preview，不是穩定版。

## English

This `0.6.3` development preview corrects Android recent-camera-media ordering when Canon exposes photos and videos through separate containers. It also improves recovery and user-facing errors for transient connection timeouts during bulk read-only operations. It is a backward-compatible patch for `0.6.2`.

### Recent Media

- Recent capture now merges photo and video containers by Canon media-info modification time when that evidence is available, so months-old videos no longer appear between the newest photos because of container round-robin ordering.
- Timestamp enrichment remains bounded. When the camera does not provide a date or the metadata request temporarily fails, the UI retains deterministic camera-container order instead of inventing a capture date.

### Bulk Read-Only Operations

- Thumbnail, preview, original download, and pre-Serein staging retry transient I/O interruptions a limited number of times, using a fresh destination on every attempt so partial content is never reused.
- State-changing metadata writes and deletion are not blindly retried because the camera may have applied an operation before its response was lost.
- Control mode now presents localized English or Traditional Chinese timeout and reconnection guidance, while Debug diagnostics retain the original exception.

### Validation And Limitations

- PR #178 passed Android unit tests, Lint, APK and signer smoke tests, plus the Pixel API 34 and API 36 UI matrices.
- An HTC U24 Pro passed the localized timeout Compose test through a separate debug package without replacing the installed Development Preview.
- The Canon EOS R6 Mark III was powered off during this validation, so physical cross-container recent ordering and interrupted-transfer recovery remain pending for the next camera session. This release makes no new model-compatibility claim from the automated evidence.
- Product behavior changes only on Android in this release. PC and iOS retain version-aligned artifacts without corresponding behavior changes.
- `open-eos-control-android-0.6.3-debug.apk` retains the stable development signer and can update matching previews from v0.1.5 onward. This remains a Development Preview, not a stable release.
