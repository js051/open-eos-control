# Open EOS Control v0.1.5 Development Preview

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

這是 Open EOS Control 的第六個開發預覽版。功能內容延續 `0.1.4` 的 Android 相機式方向操作、跨平台亮度波形圖與 3D LUT；本版重點是建立固定 Android 開發簽章，讓後續開發版可以直接覆蓋更新。

### Android 更新說明

- `0.1.4` 與更早版本使用 GitHub runner 臨時 debug key，簽章指紋不固定。安裝 `0.1.5` 前可能需要最後一次解除安裝。
- `0.1.5` 是固定開發簽章的起點；後續使用同一指紋與更高 `versionCode` 的開發版可直接更新。
- 公開憑證 SHA-256：`c2d4ad020b223e4d854f17f41aa6fcde5177b57dacc7be70b9f2f2a07f7cfdba`。
- 私鑰與密碼不在 Git 中；Actions 只在 runner 暫存目錄還原 keystore，並在上傳前驗證 APK 只有一位 signer 且指紋相符。

### 下載

- `open-eos-control-android-0.1.5-debug.apk`：使用固定開發簽章的 Android 可側載版本。
- `open-eos-control-bridge-windows-x64-0.1.5.exe`：Windows x64 單檔 Desktop Bridge。
- `open_eos_control_bridge-0.1.5-py3-none-any.whl` 與 `.tar.gz`：Desktop Bridge Python 套件。
- `SHA256SUMS.txt`：所有附件的 SHA-256 校驗值。

### 已知限制

- 此簽章只用於開發預覽版，不是正式商店發佈簽章。
- 並非所有功能都已在 EOS R6 Mark III 完成完整真機回歸；功能仍以相機或 backend 的可用能力公告為準。
- iOS 仍不提供已簽署 IPA，Windows USB 仍需系統提供 `gphoto2`／libgphoto2。

## English

This is the sixth Open EOS Control development preview. It carries forward the Android camera-style orientation behavior, cross-platform luminance waveform, and 3D LUT work from `0.1.4`. This release establishes a stable Android development signing identity so later previews can be installed as updates.

### Android Update Notes

- Versions `0.1.4` and earlier used ephemeral GitHub runner debug keys. Installing `0.1.5` may therefore require one final uninstall.
- `0.1.5` is the stable development-signing baseline. Later previews with the same fingerprint and a higher `versionCode` can update it in place.
- Public certificate SHA-256: `c2d4ad020b223e4d854f17f41aa6fcde5177b57dacc7be70b9f2f2a07f7cfdba`.
- The private key and passwords are not stored in Git. Actions restores the keystore only under the runner temporary directory and verifies that the APK has exactly one signer with the pinned fingerprint before upload.

### Downloads

- `open-eos-control-android-0.1.5-debug.apk`: sideloadable Android build using the stable development signer.
- `open-eos-control-bridge-windows-x64-0.1.5.exe`: single-file Windows x64 Desktop Bridge.
- `open_eos_control_bridge-0.1.5-py3-none-any.whl` and `.tar.gz`: Desktop Bridge Python packages.
- `SHA256SUMS.txt`: SHA-256 checksums for every attached file.

### Known Limitations

- This identity signs development previews only; it is not a production app-store signing identity.
- Not every capability has completed a full EOS R6 Mark III physical regression pass. Controls remain gated by camera/backend advertisement.
- This release still has no signed iOS IPA, and Windows USB control still requires system-provided `gphoto2`/libgphoto2.
