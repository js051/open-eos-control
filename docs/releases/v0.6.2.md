# Open EOS Control v0.6.2 Development Preview

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

這個 `0.6.2` 開發預覽版改善 Android 在 Canon 相機暫時忙碌或剛喚醒時的曝光能力穩定性，並修正 Live View 在固定相機操作版面中的顯示位置與互動座標。這是 `0.6.1` 的向下相容修正版。

### 相機工作階段

- shooting settings 暫時刷新失敗時保留該工作階段最後一次有效結果，不再因單次錯誤讓 ISO、Tv、Av、WB 從介面消失。
- 只有相機實際公告同版本 GET 與 PUT 時，才會從個別 ISO、Tv、Av、WB 資源恢復主要曝光控制；不推測未公告能力，也不加入機型硬編碼。

### Live View 版面

- 解碼畫面現在置中於頂部相機狀態列與底部曝光／拍攝控制之間，不再以整個螢幕中心計算而顯得偏移。
- Tap Focus、Click WB、對焦回饋、監看輔助與快門閃白共用同一 viewport，避免顯示位置與實際操作座標不一致。

### 驗證與限制

- Canon EOS R6 Mark III 在實體 HTC U24 Pro 上經相機 Wi-Fi 直連，喚醒後成功讀取 ISO、Tv、Av、WB abilities，並解碼 multipart JPEG Live View。
- PR #176 的 Android 單元測試、Lint、APK、簽章 smoke test，以及 Pixel API 34／36 UI 矩陣均通過。
- 本次實機流程是在相機手動喚醒後重新連線；尚未宣稱既有 session 能自動跨越完整睡眠／喚醒週期。實機曝光寫入與拒絕後回復也未在本次非破壞性流程中操作。
- 本版產品變更只在 Android；PC 與 iOS 維持同版發行產物，沒有新增相對應介面功能。
- `open-eos-control-android-0.6.2-debug.apk` 沿用固定開發簽章，可覆蓋安裝 v0.1.5 之後的同簽章預覽版。本版仍是 Development Preview，不是穩定版。

## English

This `0.6.2` development preview improves Android exposure-capability resilience while a Canon camera is temporarily busy or has just been woken, and corrects Live View placement and interaction coordinates within the fixed camera layout. It is a backward-compatible patch for `0.6.1`.

### Camera Session

- A transient shooting-settings refresh failure now retains the last valid result for that session instead of removing ISO, Tv, Av, and WB from the UI.
- Primary exposure controls recover from individual ISO, Tv, Av, and WB resources only when the camera advertises matching same-version GET and PUT operations. The client neither invents unadvertised capabilities nor hardcodes a camera model.

### Live View Layout

- The decoded frame is centered between the camera header and exposure/capture controls instead of against the entire screen.
- Tap Focus, Click WB, focus feedback, monitoring assists, and capture flash share the same viewport so visible and interactive coordinates remain aligned.

### Validation And Limitations

- A physical HTC U24 Pro connected directly to a Canon EOS R6 Mark III over camera Wi-Fi after wake, read the ISO, Tv, Av, and WB abilities, and decoded multipart JPEG Live View.
- PR #176 passed Android unit tests, Lint, APK and signer smoke tests, plus the Pixel API 34 and API 36 UI matrices.
- The physical pass reconnected after manually waking the camera. It does not yet prove that an existing session automatically survives a complete sleep/wake cycle. Physical exposure writes and rejected-write recovery were not invoked during this non-destructive pass.
- Product behavior changes only on Android in this release. PC and iOS retain version-aligned artifacts without a corresponding UI feature change.
- `open-eos-control-android-0.6.2-debug.apk` retains the stable development signer and can update matching previews from v0.1.5 onward. This remains a Development Preview, not a stable release.
