# Open EOS Control v0.1.7 Development Preview

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

這是 Open EOS Control 第八個開發預覽版。此版把 7 月 31 日進入 `main` 的相機式方向顯示正式打包，並加入相機時鐘同步與 Canon 自動亮度優化控制。

### Android 方向顯示

- 拍攝布局固定在裝置自然顯示軸；快門、曝光列、工具列與設定面板外框不會因姿態重新排版。
- 圖示、短標示、曝光值與狀態內容在固定控制槽內轉向。90／270 度時，完整取景提示改沿 Live View 長軸量測與排列，不會刪除繁中或英文說明。
- 曝光選擇器、Live View 設定與其他閱讀型面板會交換量測軸；橫拿手機時以側邊面板呈現，避免窄欄、裁切與文字互相覆蓋。
- App 直接遵循 Android 公開的系統自動旋轉設定。從快速設定關閉時會立即歸零控制方向並停用方向感測，回到 App 後再核對一次。
- 診斷報告包含 `productVersion`、`systemAutoRotationEnabled` 與 `controlRotationDegrees`，可用來確認安裝版本與實際方向政策。

### 相機控制

- Android、iOS 與 Desktop Bridge 新增能力限制的相機日期／時間同步，寫入後必須由 backend 回讀驗證。
- Android USB/PTP 與 libgphoto2 Desktop Bridge 新增 Canon Auto Lighting Optimizer。只有至少兩個已驗證安全選項時才顯示一般控制；R6 Mark III 單一 `x3` 快照仍只供診斷，不猜測選項語意。
- 保留現有 Live View、曝光、拍照、錄影、媒體與監看輔助行為。

### 下載

- `open-eos-control-android-0.1.7-debug.apk`：使用固定開發簽章的 Android 安裝包，可直接更新 `0.1.5` 以上預覽版。
- `open-eos-control-bridge-windows-x64-0.1.7.exe`：Windows x64 單檔 Desktop Bridge。
- `open_eos_control_bridge-0.1.7-py3-none-any.whl` 與 `.tar.gz`：Desktop Bridge Python 套件。
- `SHA256SUMS.txt`：所有附件的 SHA-256 校驗值。

### 已知限制

- 此簽章只供開發預覽，不是正式商店發布簽章。
- 尚未完成所有能力在 EOS R6 Mark III 上的完整實體回歸；控制仍以相機與 backend 公告能力為準。
- 此版仍不提供已簽署 iOS IPA；Windows USB 控制仍需要系統可用的 `gphoto2`／libgphoto2。

## English

This is the eighth Open EOS Control development preview. It packages the camera-style orientation work merged on July 31 and adds camera clock synchronization and Canon Auto Lighting Optimizer control.

### Android Orientation

- The capture composition stays on the device's natural display axis. The shutter, exposure rail, toolbar, and settings frame do not reflow with posture.
- Icons, compact labels, exposure values, and status atoms rotate inside stable slots. At 90/270 degrees, complete viewfinder guidance is measured and arranged along the Live View long axis without dropping English or Traditional Chinese copy.
- Exposure pickers, Live View settings, and other reading-heavy surfaces swap measurement axes. Sideways use presents them as readable side panels instead of narrow, clipped columns.
- The app follows Android's public system auto-rotate setting. Disabling it in Quick Settings immediately resets control rotation and stops the orientation listener, with another reconciliation when the app regains focus.
- Diagnostic reports include `productVersion`, `systemAutoRotationEnabled`, and `controlRotationDegrees` so the installed build and effective policy can be verified.

### Camera Control

- Android, iOS, and the Desktop Bridge add capability-gated camera date/time synchronization with mandatory backend readback verification.
- Android USB/PTP and the libgphoto2 Desktop Bridge add Canon Auto Lighting Optimizer. Normal controls require at least two proven-safe choices; the R6 Mark III single-value `x3` snapshot remains diagnostic-only rather than guessing semantics.
- Existing Live View, exposure, capture, recording, media, and monitoring-assist behavior remains available.

### Downloads

- `open-eos-control-android-0.1.7-debug.apk`: Android package using the stable development signer; it can update previews from `0.1.5` onward in place.
- `open-eos-control-bridge-windows-x64-0.1.7.exe`: single-file Windows x64 Desktop Bridge.
- `open_eos_control_bridge-0.1.7-py3-none-any.whl` and `.tar.gz`: Desktop Bridge Python packages.
- `SHA256SUMS.txt`: SHA-256 checksums for every attached file.

### Known Limitations

- This identity signs development previews only; it is not a production app-store signing identity.
- Not every capability has completed a full EOS R6 Mark III physical regression pass. Controls remain gated by camera/backend advertisement.
- This release still has no signed iOS IPA, and Windows USB control still requires system-provided `gphoto2`/libgphoto2.
