# Open EOS Control v0.5.0 Development Preview

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

這個 `0.5.0` 開發預覽版把 Android 相機媒體整理改成可實際處理大量素材的選取流程。使用者可以從剛拍完的最近素材開始，長按後直接拖過多個項目，並對選取內容執行下載或相機支援的後續操作，不必逐張開啟選單。

### Android 媒體多選

- 長按任一素材進入選取模式，繼續拖曳即可選取連續範圍；從已選項目開始則可拖曳取消範圍。
- 手指停在清單上緣或下緣時會持續自動捲動，可跨越目前畫面選取大量素材。
- 選取以穩定媒體 ID 保存；切換照片／影片篩選或排序時不會把暫時不可見的選取項目遺失。
- 提供全選、清除與返回退出，並加入英文／繁中、選取狀態語意、長按動作與放大字體版面測試。

### 批次操作

- 批次下載透過 Android 系統資料夾選擇器寫入使用者指定位置，並顯示目前檔名、項目進度與位元組進度。
- 相機有公告對應能力時，可批次保護／解除保護、封存／取消封存、設定 0-5 星、設定 0/90/180/270 度顯示旋轉，以及一次確認後刪除。
- 相機傳輸一次只可靠處理一個命令，因此批次工作依序執行；單項失敗不會中止其餘項目，完成後會分別顯示成功與失敗數量及部分失敗檔名。
- 刪除成功的項目會立即從清單移除；失敗項目保留選取，方便重試。任何拒絕、逾時或不支援回應都不會被回報為成功。

### 下載與限制

- `open-eos-control-android-0.5.0-debug.apk` 使用既有固定開發簽章，可覆蓋安裝 v0.1.5 之後的同簽章預覽版。
- Release 同時維持 Windows x64 Desktop Bridge、Bridge Python wheel/source archive、`BUILD-PROVENANCE.json` 與 SHA-256 校驗值；PC 與 iOS 本版沒有同步 Android 的拖曳多選介面。
- 本批沒有在實體 EOS R6 Mark III 上執行批次下載或媒體修改。操作仍依相機／transport 公告能力顯示，真機 Wi-Fi 與 USB/PTP 的大量素材、部分失敗及取消行為需要後續驗證。
- 本版仍是 Development Preview，不是穩定版；尚未有真機證據的能力會保留明確限制，不作未驗證的相容性宣稱。

## English

This `0.5.0` development preview turns Android camera-media management into a practical selection workflow for large libraries. Starting from the newest captures, users can long-press and drag across items, then download the selection or run operations advertised by the active camera without opening every item menu.

### Android Media Selection

- Long-press an item to enter selection and continue dragging to select a contiguous range. Starting from a selected item clears the dragged range.
- Holding near the top or bottom edge continuously scrolls the grid so a gesture can cover items beyond the current viewport.
- Stable media IDs retain selected items across photo/video filters and sort changes, including selections that are temporarily hidden.
- Select all, clear, and Back-to-exit actions include English and Traditional Chinese strings, selected-state semantics, accessible long-click behavior, and enlarged-text coverage.

### Batch Operations

- Batch download uses Android's system folder picker and reports the current filename, item progress, and byte progress.
- When the camera advertises the matching capability, the selection can be protected or unprotected, archived or unarchived, rated from 0 through 5, assigned a 0/90/180/270-degree display rotation, or deleted after one confirmation.
- Camera transports reliably handle one command at a time, so batch work is sequential. One failed item does not stop the remaining items; the final result separates success and failure counts and names a bounded set of failed files.
- Successfully deleted items leave the library immediately, while failed items remain selected for retry. Rejections, timeouts, and unsupported operations are never reported as success.

### Downloads And Limitations

- `open-eos-control-android-0.5.0-debug.apk` uses the existing stable development signer and can update matching previews from v0.1.5 onward.
- The release also retains the Windows x64 Desktop Bridge, Bridge Python wheel/source archive, `BUILD-PROVENANCE.json`, and SHA-256 checksums. PC and iOS do not receive Android's drag-selection UI in this version.
- This batch did not execute batch download or metadata mutation on a physical EOS R6 Mark III. Actions remain capability-gated by the active camera and transport; large-library, partial-failure, and cancellation behavior over real Wi-Fi and USB/PTP still require validation.
- This remains a Development Preview rather than a stable release. Capabilities without physical evidence retain explicit limitations and make no unverified compatibility claim.
