# Open EOS Control v0.1.1 Development Preview

[繁體中文](#繁體中文) | [English](#english)

## 繁體中文

這是 Open EOS Control 的第二個開發預覽版，主要改善 Android 相機操作介面的方向行為，並新增依相機能力開放的 Bulb 長曝光控制。本版本仍以 Canon EOS R6 Mark III 的實機驗證為優先，不應視為正式拍攝工具。

### 下載

- `open-eos-control-android-0.1.1-debug.apk`：可直接側載的 Android debug build，使用 Android SDK debug 憑證簽署。
- `open_eos_control_bridge-0.1.1-py3-none-any.whl`：PC Desktop Bridge Python wheel。
- `open_eos_control_bridge-0.1.1.tar.gz`：PC Desktop Bridge source distribution。
- `SHA256SUMS.txt`：所有附加檔案的 SHA-256 校驗值。

Android APK 並非正式簽章；若舊版使用不同憑證，可能需要先解除安裝。Desktop Bridge 的 USB 控制仍需要系統提供的 `gphoto2`／libgphoto2。iOS 本版仍只發布原始碼，實體裝置 App 必須由 Xcode 建置及簽章。

### 主要更新

- Android 採相機 App 類型的固定拍攝版面：手機轉向不會重排整頁，只旋轉必要的控制、圖示及狀態文字。
- 依 Android 系統自動旋轉開關決定控制是否轉向；關閉時保持自然方向，開啟時支援 90／180／270 度。
- 橫向文字與設定面板會交換量測軸後重新排版，避免單純旋轉造成裁切、重疊或可讀範圍不足。
- CCAPI、Android USB/PTP、Desktop Bridge、PC 與 iOS 新增依能力開放的 Bulb 長曝光開始／停止與計時顯示。
- Bulb 期間暫停主動 Live View 輪詢，結束與失敗清理會採完整按壓／釋放順序，避免相機快門停留在按下狀態。
- Android、iOS、Bridge 與 Simulator 的自動測試同步擴充。

### 已知限制

- 並非所有功能都已在 EOS R6 Mark III 完成完整實機回歸。
- Bulb 只會在相機公告完整能力且拍攝模式確實為 Bulb 時出現。
- Android APK 僅供測試；本版不提供已簽署的 iOS IPA。
- Canon CCAPI RTP 目前只處理 H.264 影像，不包含音訊。

## English

This is the second Open EOS Control development preview. It improves Android camera-style orientation behavior and adds capability-gated Bulb long exposure. Physical validation still prioritizes the Canon EOS R6 Mark III, and this build should not be treated as a production capture tool.

### Downloads

- `open-eos-control-android-0.1.1-debug.apk`: directly sideloadable Android debug build signed with the Android SDK debug certificate.
- `open_eos_control_bridge-0.1.1-py3-none-any.whl`: PC Desktop Bridge Python wheel.
- `open_eos_control_bridge-0.1.1.tar.gz`: PC Desktop Bridge source distribution.
- `SHA256SUMS.txt`: SHA-256 checksums for all attached files.

The Android APK is not production-signed and may require uninstalling an older build if its signing certificate differs. Desktop Bridge USB control still requires system-provided `gphoto2`/libgphoto2. iOS remains source-only; physical-device builds must be built and signed with Xcode.

### Highlights

- Android now keeps camera capture geometry fixed while rotating only essential controls, icons, and status text.
- Control rotation follows the Android system auto-rotate setting and supports 90, 180, and 270 degrees when enabled.
- Sideways text and settings panels exchange measurement axes before layout, preventing clipping and overlap caused by graphics-only rotation.
- Capability-gated, timed Bulb start/stop now spans CCAPI, Android USB/PTP, Desktop Bridge, PC, and iOS.
- Active Live View polling pauses during Bulb exposure, while completion and failure cleanup use balanced press/release sequences.
- Android, iOS, Bridge, and Simulator test coverage has been expanded.

### Known Limitations

- Not every feature has completed a full physical regression pass on the EOS R6 Mark III.
- Bulb appears only when the backend advertises the complete operation and the camera is actually in Bulb mode.
- The Android APK is for testing only. No pre-signed physical-device iOS IPA is provided.
- Canon CCAPI RTP currently handles H.264 video only, without audio.
