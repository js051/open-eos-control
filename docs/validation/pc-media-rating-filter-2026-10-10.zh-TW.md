# PC 已載入媒體的評分篩選與排序

本批延續 P2 相簿挑片功能。日期篩選之外，PC 可依已載入素材的評分縮小清單；不會為篩選逐檔查詢相機 metadata，也不要求評分寫入能力。

## 公開行為

- 篩選包括全部、未評分（已知數字 0）、至少 1／2／3／4 星、5 星及未知評分。
- 只有整數數字 0–5 是已知評分。缺失、null、字串、布林、越界值均屬未知，不能默認為 0。
- 評分高至低／低至高排序都將未知放在最後；同分與未知之間保留原清單順序。評分排序不顯示日期分組標題。
- 評分、日期與媒體種類取交集。摘要顯示已載入數量、符合數量及未知評分數，並不聲稱掃描整張記憶卡。
- 套用／清除評分條件將分頁回到首頁，保留已載入陣列、日期條件、既有預覽與下載狀態。取消對話框不變更條件。
- 若目前預覽被條件排除，該預覽仍可保留，導覽限制為該單一項目。評分排序時，獨立的最新拍攝素材也不會插到排序清單前方；明確開啟該素材時以單項預覽呈現。
- 舊連線開啟的對話框不能改動新連線，即使連線 ID 字串重用。斷線退休草稿並恢復全部評分。
- 原生 dialog 使用現有英文／繁體中文、鍵盤與樣式契約。這裡的來源檢查不等於視覺驗收。

## 本地證據與限制

新增 helper 單元測試 11 項：原實作 1 通過／10 失敗，候選 11 通過。原有模組測試保持原 assertions。

新增 production callback 測試 9 項，包含 session、取消、清除、唯讀能力、日期交集、preview/download 身分及未知評分。獨立來源審查發現最新拍攝素材可能被插到評分排序首位，新增受控測試實際重現 8 通過／1 失敗，最小修正後 9 通過（含雙排序方向及 unknown／0 控制）。測試以 VM 擷取 production callbacks，render/navigation 使用 stub；不宣稱已驗原生 dialog 或實際影像解碼。

正常 browser suite 已加入英文／繁體中文、200% 字體、兩方向 viewport、鍵盤焦點／Escape、日期交集、篩選／排序及相機請求計數檢查。此文件建立時 browser/backend 尚未執行，待本批必要正常 CI。完整 App、視覺與實體相機驗收依使用者指示集中於功能開發後，不以 Node 結果替代。

沒有更改 CI classifier、必要 gates、相機傳輸契約或系統權限。新增功能的發布性質應按 repo minor 版本政策另行評估；本批不發布版本，既有 release HOLD 保留。
