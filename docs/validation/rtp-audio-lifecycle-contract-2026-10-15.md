# RTP 音訊生命週期與證據契約（2026-10-15）

## 範圍

沿既有 CCAPI RTP/AAC 音訊路徑，對齊手動開啟、持續解碼、輸出觀察、靜音、背景／連線退休與手動恢復。音訊錯誤不應破壞仍可使用的影像串流。此文件定義共同驗收，不代表原生 SDK、瀏覽器或實機驗證已完成。

## 證據層次

1. Requested/enabled：使用者意圖及本地管線啟動，不是音訊成功證據。
2. Decoder input：AAC 已交給解碼器，不代表已有 PCM。
3. Actual decoded PCM：解碼器實際產生非空、格式有效的 PCM；以本地單調時間記錄，不冒充相機錄製時間。
4. Submitted PCM：已排程或輸出 API 接受的音框，不代表已呈現。
5. Supported output progress：平台可支援的 player-render callback、AudioTrack playback head 或 browser output timestamp 前進，且與本輪已提交音框相交。只代表軟體／平台輸出進展；音量、路由、喇叭與人耳聽見皆未證明。

未提供輸出觀察 API 時，輸出進度保留 unknown；不能僅因無法觀察而關閉仍可使用的聲音。若 API 存在卻沒有進展，標示 output progress unverified/stalled，不推論相機故障。UI、計數及時間戳必須保持這些層次，不能把 submitted 欄繼續命名為 played。

## 時效與恢復

- PCM freshness 上限 1 秒。不得播放已知過期資料，或將沒有新資料的快取當作持續進展；仍新鮮的最新後端 PCM 可用於新的手動開啟。
- 手動開啟至第一筆 actual PCM、以及最後 actual PCM 後的等待上限均為 5 秒。輸入封包、空 PCM、排程、格式切換或 discontinuity 不得更新 actual-PCM deadline。
- 有支援輸出觀察時，等待輸出進展上限 5 秒；只記錄與本輪 PCM 有關的輸出，不以獨立空轉時鐘冒充本輪音訊。
- 靜音、背景、來源／連線退休、失流或失敗，應撤銷本輪意圖及輸出；恢復須再次明確手動開啟，不能前景或重新連線後自動復播。
- 暫停或排程延遲後，不能突發重播積壓的舊音訊。1 秒是已知資料／待播緩衝的新鮮期限，5 秒是等待資料或受支援輸出進展的期限，兩者分開。無輸出觀察 API 不是資料過期的證據；仍須依可取得的待播緩衝期限與退休回呼保護輸出。
- 音訊停止／釋放責任須完成才可讓新的實體輸出接手。釋放結果不確定時保留阻塞與可見失敗，不能只清除指標就宣稱已停止。

## 所有權與取消

每次手動開啟都產生新的 playback epoch，並受來源 session 與輸出實例約束。舊 fetch/resume/decoder/output completion、延遲統計與 finally 不可寫入新輪 UI、計數或輸出。靜音與退休須能即時撤銷排隊的工作。資料讀取、解碼輪詢與輸出背壓應可取消且有界；取消不等於成功輸出。影像管線既有的 owner fence 與停止責任不因音訊修正而放寬。

## 最低測試旅程

- 開啟但未有 PCM；連續 AAC／空輸出不可偽造成功或無限延後時限。
- 真 PCM 與 submitted 分別計數；提交後輸出時鐘尚未前進仍為未證實。
- 支援的輸出進展正常、停止、倒退／重置，以及不支援觀察的分支。
- 最後 AAC 後解碼器延遲產生 PCM；持續 drain，不依賴下一個封包。
- 靜音／背景／換連線後，舊解碼、完成回呼及統計到達；新輪不受影響。
- 快速關閉再開啟、輸出背壓及取消，舊實體資源未退休不得競用。
- 失流後明確手動重試，新的 epoch 可成功；音訊失敗不使正常影像失效。

## 驗證限制

1 秒／5 秒是依本地單調時鐘判斷與發起清理的軟體期限；timer、原生 poll、事件迴圈及 OS 排程有觀察／執行延遲，並非實體輸出的 hard-real-time 保證。

本批只做現有工具可完成的本地程式與合成測試。Swift/Xcode、Android SDK/AudioTrack 實際執行、瀏覽器音訊裝置輸出、實體相機、耳聽、效能及背景 OS 行為仍需獨立驗證。API 形狀替身或來源檢查不等於平台編譯。三個開發候選包含相同契約文件，不表示三平台產品或實機行為已全部對齊。

## PC 同步解碼與原生延遲輸出的差異

PC 的 PyAV 路徑同步取出當次 parse/decode/resample 回傳的全部 PCM；既有單個 LATM access-unit fixture 可驗不依賴下一個封包的具體案例。它沒有 Android codec poll 或 iOS converter drain 相同的獨立延遲輸出入口，不能由該 fixture 推論任意解碼器在回傳空資料後仍可被持續 poll。不得為滿足測試而在 live stream 任意 flush EOS。此 API 與驗證差異須保留在交付記錄。
