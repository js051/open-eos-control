# Capture configuration receipt host boundary

The runner injects unchanged production createDirectory, setFileNaming, postJson,
putJson, requestJson, endpoint definitions and value accessors. It also compiles
complete production evidence, strict body/JSON readers and naming model.

HostClient explicitly substitutes HTTP Call/Response/InputStream, operation
advertisement, readback loading and typed JSON decoding. StrictMediaJson still
checks the actual serialized JSON bytes before the adapter. Neither this fixture
nor its success establishes real OkHttp, sockets, Android, UI or camera execution.

The baseline must compile successfully and fail the six named partial-ACK runtime
assertions. Current source must pass all twelve tests. Complete status, JSON/body,
original error, owner/cancel and unrelated-range controls must stay green.
